Waveform 0.2.0 adds sound discovery, a customizable voice studio, and a one-click Windows launcher.

Download **Waveform Setup 0.2.0.exe** and run it. It installs the app and creates desktop and Start-menu shortcuts. Future launches need no Node.js, command prompt, or build commands. The optional **Waveform-0.2.0-win.zip** can be extracted in full and launched with Waveform.exe. These builds are unsigned.

- Search Wikimedia Commons audio, preview locally, and download into the app with retained source and license credits. No API key required; online search needs Internet access.
- Times New Roman throughout the interface, a new multiresolution Windows icon, sorting, and reduced-motion settings.
- Live microphone pitch, bass, distortion, and synthetic texture, with fan-inspired Hulk, Venom, Lash, Rem, Heavy, Pyro, and GLaDOS presets. These are stylized DSP effects, not cloned or official character voices. Pitch shifting adds roughly 40–100 ms of processing delay.
- Microphone/sound/output boosts, adjustable noise gate, and requested echo cancellation. Keep Discord and Windows playback on headphones to avoid returning other people's voices to the cable.
- Single-instance launching, a system tray menu, optional close-to-tray, start-minimized, and Windows-login startup.

VB-CABLE remains a separately installed third-party driver. In Waveform choose your physical microphone and CABLE Input; in Discord use CABLE Output as input and headphones as output. The routing guide offers the official download and validated driver-installer launch.

The release workflow checks desktop startup and builds the Windows downloads. Automated library tests use simulated API responses. Physical Discord routing, character resemblance, and compatibility with individual fullscreen games must be tested on your computer.
